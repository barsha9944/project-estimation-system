
BEAS extensively uses version control systems for the enhancement and development projects. All the project documents and source codes are kept in SVN/GIT for different functionalities, and we maintain a project directory for this purpose.

Any change in document source code is recorded in different versions in SVN/GIT. The entire history is maintained in a version control system.

It starts with proposals and other documents like contract, contract review, requirement document (SRS), SRS review, SDD review, code review, project status, project review, test plan, test case, test case review etc.

Finally, during delivery, we deliver the latest source code and deliverables to our clients with proper release notes.
