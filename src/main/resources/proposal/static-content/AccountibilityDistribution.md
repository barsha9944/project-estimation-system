
To ensure smooth project execution for technical development, it is important to clearly identify the roles and responsibilities of BEAS and the customer.

The following table identifies the major responsibilities of both BEAS and the customer during the engagement lifecycle.

| Activities | Customer Responsibility | BEAS Responsibility |
|---|---|---|
| Detailed Project Plan for Technical Development | Approve | Create |
| Preparation of Functional Specification (SRS) | Approve | Create |
| Design Document | Approve | Create |
| Design & Build | Review | Create |
| SIT Test Cases and Execution Report | Approve | Create & Perform |
| Deployment | Arrange Resources | Perform |
| Acceptance Testing | Perform / Approve | Assist |
| Support for 2 Months | Log Issues | Perform Fixes |

## Governance Notes

- BEAS will provide regular status updates and milestone tracking.
- Customer approvals are required before phase signoff.
- Delays in approvals or resource availability may impact delivery timelines.
- Deployment activities will be coordinated jointly between BEAS and customer teams.
